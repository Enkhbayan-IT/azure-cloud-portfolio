# Resource Tagging Notes

Resource tags are key-value pairs assigned to:
- Resources
- Resource Groups
- Subscriptions

Purpose:
- Add business context
- Organize resources
- Improve cost tracking
- Support governance

Example tags:
- Environment = Dev
- CostCenter = 1702
- Department = Logistics

Important:
- Resource Group tags are NOT inherited by resources.
- Tags are metadata, not security permissions.
