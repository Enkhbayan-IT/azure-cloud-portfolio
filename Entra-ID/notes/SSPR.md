# Self-Service Password Reset (SSPR) Notes

## Overview

Self-Service Password Reset (SSPR) allows users to reset or change their passwords without helpdesk or administrator assistance.

This improves:
- User productivity
- Identity security
- Operational efficiency

---

## License Requirement

SSPR requires:
- Microsoft Entra ID P1
or
- Microsoft Entra ID P2

---

## Common Verification Methods

Users can verify their identity using:
- Microsoft Authenticator
- SMS verification
- Email verification
- Security questions

---

## Basic Workflow

User forgets password
→ Verify identity
→ Reset password
→ Sign in again

---

## Configuration Path

Microsoft Entra ID
→ Password reset

---

## Benefits

- Reduces helpdesk workload
- Faster password recovery
- Improved user experience
- Better identity security
- Supports MFA verification

---

## Important Notes

- Typically used for non-administrator users
- Often combined with MFA
- Common enterprise identity feature
- Supports Zero Trust security principles

---

## Best Practice

Use:
- MFA
- Strong password policies
- Secure authentication methods

together with SSPR for improved account protection.
