# Azure CLI Infrastructure Labs

This folder contains Azure CLI-based scripts and notes for deploying and managing Azure infrastructure resources.

It complements the PowerShell labs in this repository by showing how the same Azure resources can be managed using Azure CLI commands.

## Topics

- Resource Group
- Virtual Network (VNet)
- Subnet
- Network Security Group (NSG)
- Public IP
- Network Interface (NIC)
- Virtual Machine (VM)
- Storage Account
- App Service Plan and Web App

## Goal

The purpose of this section is to demonstrate practical Azure infrastructure deployment using Azure CLI as part of a cloud engineering portfolio.
