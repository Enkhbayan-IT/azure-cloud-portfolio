# Azure Site Recovery (ASR)

## Overview

Azure Site Recovery (ASR) is Azure’s Disaster Recovery service.

It is used to:

- Replicate workloads
- Protect virtual machines
- Recover applications quickly
- Minimize downtime during disasters

Azure Site Recovery supports:

- Azure Virtual Machines
- On-premises servers
- Hybrid workloads
