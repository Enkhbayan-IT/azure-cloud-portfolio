# Azure File Recovery

## What is File Recovery?

Allows restoring:
- Individual files
- Individual folders

from a VM backup.

---

## Recovery Process

Azure provides:

- Script / executable
- Temporary password

The script maps recovery drives onto the local machine.

---

## Important Concept

File recovery connects to:
- Backup restore point

NOT:
- Actual Azure VM

---

## Use Cases

- Deleted files
- Corrupted folders
- Restore configuration files
- Recover important documents

---

## Important Learning

Recovery drives shown on Windows are mounted from backup snapshots.

They are not live VM disks.
